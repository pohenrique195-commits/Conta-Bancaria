# Sistema Bancário em Java

Sistema bancário desenvolvido em **Java** com foco na aplicação de conceitos de **Programação Orientada a Objetos (POO)**.

## Funcionalidades

* Cadastro de correntistas
* Criação e acesso de contas bancárias
* Contas corrente e poupança
* Depósitos e saques
* Controle de limite da conta corrente
* Investimentos
* Consulta de saldo
* Histórico de transações
* Diferentes taxas de rendimento
* Validação de entradas do usuário

## Conceitos utilizados

* Classes e objetos
* Encapsulamento
* Herança
* Polimorfismo
* ArrayList
* Tratamento de exceções
* Sobrescrita de métodos

> Projeto em desenvolvimento. A estrutura atual será posteriormente refatorada para melhorar a organização, manutenção e qualidade do código.
